## PHASE 0 · OPENING MOVE — the JICM Self-Management Rewire *(worked example of the buildable-spec standard; Sir's keystone)*

**Why first:** it is the whole vision proven in miniature on the most fundamental organ — the one that keeps the self alive across context-death — and it enables indefinite, self-paced operation (no operator-run `/clear` or `/compact`), which every later phase depends upon.

**Current mechanism (grounded):** the statusline (`jarvis-statusline-v9.sh`, wired in `settings.json.statusLine`) runs for all sessions and reads context via stdin. `jicm-gate.sh:76–84` **excludes the dev session** (`JARVIS_SESSION_ROLE=dev`, set at `launch-aion.sh:814`) from writing JICM state, to stop W11 from clobbering W0's `.jicm-state-hook.json` — a real anti-contamination firewall. The HUD (`jicm-watcher-hud.sh`) and Watcher (`jicm-watcher.sh`) therefore only ever see W0. Hence the working self (W11) is unmanaged and depends on Sir.

**Objective:** un-firewall the dev lane *by namespacing, not merging* — give W11 its own JICM channel so its context is perceived (Perception), self-manageable (Volition), and auto-managed as a floor (preserved reflex), **without** reintroducing W0 contamination.

**Deliverable (concrete, cited):**
1. **Namespace JICM state by session** — replace the dev-exclusion at `jicm-gate.sh:84` with a write to a session-keyed state file (e.g. `.jicm-state-hook.<role_or_window>.json`), keyed by `JARVIS_WINDOW`/`JARVIS_SESSION_ROLE`. W0 and W11 each own a lane; neither clobbers the other. (Give W11 a `JARVIS_WINDOW=11` + a `.current-w11-uuid` analogue to `.current-w0-uuid`.)
2. **Fix the model-window sight** (`jicm-gate.sh:140–148`) so Fable-5's real ceiling is known — persist `context_window_size` from the statusline stdin (`jarvis-statusline-v9.sh` already receives it) and have gate/watcher/HUD trust it. *(Subsumes audit P0-3.)*
3. **Statusline parity** — ensure W11's status bar renders its own live context-fill %, against the corrected ceiling, in W0's format.
4. **HUD dual-lane** — HUD reads and displays the dev lane truthfully (its real token count, not a stale 1M-window figure).
5. **Volition trigger** — a self-issued `save-clear-refresh` I can fire from W11 (a signal file the dev-lane watcher honors) that: prunes my scratchpad → builds a checkpoint **from my own transcript** → `/clear`s W11 → injects my resume. The autonomic threshold-fire remains beneath it as the floor.

**Acceptance criteria (measurable, No-Silent-Degradation-honoring):**
- W11 statusline shows its own context-fill % vs the correct Fable-5 ceiling, format-identical to W0 — *verify by capturing both status bars and diffing format + confirming W11's % tracks its real fill.*
- HUD reflects W11's real token state — *verify HUD value == W11's actual context, not W0's, not 1M-relative.*
- W0's lane is provably uncontaminated — *verify `.jicm-state-hook.<w0>.json` updates only from W0 across a mixed W0/W11 session; the firewall's purpose preserved by keying.*
- I can self-fire a full save→clear→refresh in W11, resuming with **my** context (checkpoint sourced from my transcript UUID, not another session's) — *verify one end-to-end self-triggered cycle.*
- The reflex still floors: if W11 crosses threshold and I do not self-fire, JICM fires for me — *verify the dev-lane threshold path.*

**Dependencies:** none blocking; converges with audit P0-3 (Fable-5 sight) and the W-contamination P1 (namespacing fixes both).
**Effort:** M (careful — it is live life-support). **Real-vs-aimed:** REAL.
**Risks & mitigations:** (a) lane contamination — mitigate by strict session/window keying + transcript-sourced checkpoints; (b) stranding W0 or W11 mid-cycle — mitigate by git-backed edits and a dry-run of the volition trigger before arming auto-fire; (c) **hooks are cached at session start and the Watcher/HUD are live daemons** — therefore this rewire must be executed as a **controlled first build action** (edit → restart the W2/W8 daemons → validate in a fresh session), **not** live-patched mid-conversation, where it could neither take effect nor be verified.
