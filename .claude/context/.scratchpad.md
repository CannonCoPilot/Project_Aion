### Key insights / gotchas learned this session
- uv venvs ship WITHOUT pip → `pip list` returns empty; verify installs via `python -c "import X"`.

- `--dist=loadscope` needed so module-scoped fixtures (analyzed_project) build once per worker, not per test.
- Working dir matters: `.venv/bin/python` from repo root hits the LEFTOVER root .venv (3.14, no xdist). Always cd core/ for backend pytest.
