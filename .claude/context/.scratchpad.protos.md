## Artifact design decisions (do NOT redesign on resume — extend within these)
- **Two-hue semantic system, load-bearing:** teal `--teal` = *verified fact* (`.fact` block);
  ochre `--ochre` = *a line to say aloud* (`.say` block); oxide `--oxide` = *do not claim*
  (`.stop-box`). The reader navigates by left-edge colour. Do not add a fourth hue.
- Type: Iowan Old Style/Charter serif for display AND prose; system sans for labels/tables/chrome;
  SF Mono for identifiers. **No webfont URLs** — Artifact CSP blocks font CDNs (silent fallback).
- Every project = one `<article class="card">` with the identical 8-slot `<table class="slot">`.
  The uniformity is the memory device. `data-k="..."` on each card feeds the filter box.
- Tokens defined on `:root`, redefined under `@media (prefers-color-scheme:dark)` AND both
  `:root[data-theme="dark"|"light"]` so the viewer's toggle wins in both directions.
- Three interactions only: rail filter box, "Recall mode" (collapses `.card-bd`), theme toggle.
