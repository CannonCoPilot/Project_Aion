  fabrication (real file is `-07-25`).

  turns survive), stderr ALERT, `input_trimmed_tok` + `runtime_clipped` recorded. `runtime_clipped
  = 0/10` across the sweep.
- **Model = 32B.** Size crossover ~20K tokens: 8B wins below (0.857 vs 0.357) and collapses above
  (0.050 recovery on 31.7K; 2 fabrications, both on the largest inputs). **Abandoned sessions are
  large by definition** — the regime that matters is where the 8B fails.

## 3. TRAPS — all cost a debugging cycle, do not repeat
1. **`sed`/`str.replace` patching FAILS SILENTLY.** An earlier sed rewrote `if n>1]`→`if n>=1]`, so a
   later replace never matched and recency ordering was never applied to FILES — invalidating a whole
   results arm. **Rewrite whole functions; never patch-by-regex a file under active iteration.**
2. **`pkill <script>` kills the shell, NOT its in-flight python child**, which then appended a stale
   row to a truncated results file. Contamination looked legitimate.
3. **`setsid` DOES NOT EXIST on macOS.** I hit this twice — it silently no-ops the launch. Verify a
   background launch with `pgrep`, never with an unconditional `echo`.
4. **Ollama caches prompt KV** — repeated identical runs report fake-fast times (`prompt_s≈0`). Only
   first/uncached runs are honest timings.
5. **Metrics can be gamed**: the 8B once scored perfect recovery AND zero hallucination by *echoing
   the fact sheet verbatim*. Hence the `echo` metric.
6. **Salience must come from conversation PROSE only** — raw counting ranks hook files
   (`context-injector.js` 131×) above real work files. The **whitelist** must come from RAW records
   (incl. tool params) or legitimate paths get flagged as hallucinations.
7. **`$?` after a pipe is the LAST command's status**, and an unquoted `$var` may arrive as ONE arg.
   Two harness artifacts nearly produced a confidently-wrong "verified".
8. Bash 3.2 on macOS; never `set -euo pipefail` in hooks; `/Users/nathanielcannon/bin/tmux` full path.
