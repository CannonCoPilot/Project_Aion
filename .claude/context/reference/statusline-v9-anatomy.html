Row 2 is a parsed contract

jicm-actuate.sh _bar_row() greps the rendered pane for \] +[0-9]+%. Row 2 must keep the literal sequence "] " + spaces + integer + "%". Reformatting it silently breaks context actuation.

Rate limits never go blank

Claude Code emits rate_limits only while its state holds a five-hour or seven-day claim. Under overage the key disappears entirely, and v9.0 rendered an empty string — a missing capacity signal that looked like a healthy one. v9.1 falls back stdin → proxy-DB cache (marked ~) → an explicit 5h:—.

CONFIG

Why a lane might look different

Two non-obvious constraints

The script contains no persona or role branching. It builds the same three rows for every lane. A lane rendering a different layout is drift to fix in config — never a reason to edit the script.

The path must be absolute

$CLAUDE_PROJECT_DIR resolves to the satellite directory for any lane rooted outside Project_Aion/ — alfred/, DwarfCron/, WVU/, SnorkelTasks/. None of them have a .claude/scripts/, so a relative path renders nothing, silently.

Alfred's key lives in the generator

alfred/scripts/profile-loader.js overwrites alfred/.claude/settings.json wholesale and never reads the existing file. A hand-added statusLine there is wiped on the next profile load. The key must be emitted from the generator.
