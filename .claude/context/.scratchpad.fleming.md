## READ FIRST — THE THINGS THAT COST HOURS

**1. The micro1 browser is NOT the default MCP browser.** Two Chrome instances carry the
extension. A `/login/` page or `Tab <id> no longer exists` means **WRONG BROWSER**, never an
expired session. Order: `list_connected_browsers` → `select_browser` → `tabs_context_mcp`; take
the instance holding a `realm.micro1.ai` tab. Runs Chrome **Profile 1**. **Names swap** — on
2026-09-14 micro1 was "Browser 1" (`b72a12c5-0ccf-4471-aa10-ef23552ffba1`); the other
(`da3bf06e-…`) is the dev lane's. Identify by content. **Never ask the User** (ruling 2026-09-09).

**2. Never click a tab then press `Return`.** If the click did not take, the Return lands in
whatever field has focus and the page **autosaves it to the client record**. Click, screenshot,
click again. Accordions toggle — two clicks = open then shut; click once and verify.

**3. Token: `python3 scripts/realm_token.py`** pulls a fresh JWT from Chrome LevelDB unaided.
Refreshed 2026-09-15, valid to 2026-09-16 08:22.

**4. RATE LIMIT — NEW AND SERIOUS.** `get-task` is limited and the limiter counts it as
*opening a task*. 54 back-to-back gave `403 ACCOUNT_BLOCKED` — *"repeated blocks become
permanent"*. **Retrying EXTENDS the block**, and the block covers `list` too. **12 s spacing
completes 54 fetches with zero blocks.** Poll with `task_availability.py` (list-only, 3 calls);
enrich with `harvest_task_index.py` (throttled, resumable) once.

**5. Writing to platform fields:** set values via the native `HTMLTextAreaElement`/`HTMLInputElement`
setter + dispatched `input` event, from a **base64** payload. The extension's `form_input`
silently replaced 114 non-breaking spaces with ordinary ones on 154's golden — same character
count, so a length check passed.
