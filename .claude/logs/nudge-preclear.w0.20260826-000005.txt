⏺ No — and the confusion is worth clearing up precisely, because the naming is misleading.

  BASELINE_MODEL is not a visual model. It is a row clusterer.

  From collation_read.py:

  s = leaf_slope(boxes, p) if BASELINE_MODEL else 0.0
  pairs = [(b[1] - s * ((b[2] + b[3]) / 2.0 - xc), b) for b in boxes]

  It estimates a per-leaf tilt and groups glyph bounding boxes into text rows against a slope-corrected baseline. It consumes boxes and emits rows. It has no notion of region class, no
  notion of a page, and it never looks at an image. "Model" here means a model of where the baselines are on a skewed scan — nothing to do with seeing or boxing marginalia.

  So why does a row clusterer have a MarginNote score?

  Because changing how glyphs group into rows changes what the region labeller receives, and MarginNote recall moves as a consequence. MN is being used as a proxy metric to judge a
  row-clustering change.

  ★ Insight ─────────────────────────────────────
  That is the defect this project already named — one level higher up. R2.2a's acceptance criterion reads: "scored directly on RunningHead/MainText assignment, and separately from any
  downstream continuity or page-number rate. ⚠️ A primitive measured only through its consumers cannot be debugged when a consumer moves." The rule was written for the region primitive and
  then broken for the row clusterer beneath it. The row clusterer does have a direct metric — row count, S2, reading 20/20 — but the scratchpad records that S2 is blind outside the body

  ⎿  def scan_marginalia(tome: dict, streams: dict) -> dict[tuple[str, int], dict]:
         """(book, chapter) -> {source: {n_words, sample}} from each source's region-typed margin
         capture, using the tome map's chapter_pages to know which pages carry the chapter."""
         out: dict[tuple[str, int], dict] = defaultdict(dict)
         for src, s in tome["sources"].items():
             st = streams.get(src)
             if st is None:
                 continue
             for book, r in s.get("books", {}).items():
                 for ch_str, pages in r.get("chapter_pages", {}).items():
                     words: list[str] = []
                     for pg in pages:
                         words.extend(st.margin_by_page.get(pg, []))
                     if words:
                         out[(book, int(ch_str))][src] = {
                             "n_words": len(words),
                             "sample": " ".join(words[:24]),
                         }
         return out
